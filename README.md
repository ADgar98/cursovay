# Instapro

MVP социальной сети для обмена фотографиями
Добавлена связь с сервером, реализованна возможность авторизации и регистрации, так же добавление постов.
Появилась возможность просматривать посты отдельного пользователя. Так же добавлена анимация лайков и смена их состояния.
